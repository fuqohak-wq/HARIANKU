Cara Mengubah Naskah Ini Menjadi Sitasi Aktif Zotero:
Langkah 1: Klik tombol "Unduh File (.RTF for Zotero)" di kanan atas setelah naskah selesai dibuat.
Langkah 2: Buka aplikasi **Zotero Desktop** di laptop -> Klik menu Tools -> Pilih RTF/ODF Scan.
Langkah 3: Pilih file RTF Anda -> Klik Next. Zotero akan otomatis menghasilkan file Word baru dengan sitasi aktif!
